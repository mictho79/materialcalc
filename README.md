# MaterialCal

Free construction and landscaping material calculators — 25 calculators for gravel, concrete, paint, decks, fences, stairs, roof pitch, tile, drywall and more.

Built with Astro 4. Static-first, SEO-optimized, mobile-friendly. No tracking, no signup, no paywall.

## Stack
- Astro 4.16
- Vanilla JS (no framework runtime)
- CSS custom properties design system

## Dev
```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output to dist/
```

## Live calculators
Aggregates · Volume · Soil · Surfaces · Structure · Outdoor — 25 tools covering the full residential and landscaping material spectrum.
